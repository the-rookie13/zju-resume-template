系统分析 GUI Agent 执行过程中的细粒度失败，揭示不同错误真正需要哪些信息才能被有效纠正。基于这些分析，我们定义 VisualGradient ———— 一种结构化反馈信号，将终局失败转化为面向归因节点的局部视觉修复目标，并以此为核心构建免训练的测试时修复框架，使额外计算能够聚焦于具体失败状态及其受影响部分。

设计 Evolution-SOP + Episodic Memory + State Graph 的结构化演化机制：从完整 trajectory 中提取触发条件、失败模式与恢复动作，并进一步更新状态节点、修复边和转移规则；采用 evidence/scope/constraint 等约束实现 bounded harness evolution，同时保持基础模型、工具与原始上下文冻结。
